# Как узнать причину краша «Birthday Reminder keeps stopping»

Сделайте по шагам.

## Шаг 1. Пересоберите и запустите приложение

```bash
cd /Users/restart/Desktop/birthdayApp2
npx react-native run-android
```

Дождитесь краша (диалог «Birthday Reminder keeps stopping»).

## Шаг 2. Получите лог краша — один из способов

### Способ A: Лог в файле приложения (после краша)

В терминале выполните:

```bash
adb shell run-as com.birthdayapp cat /data/data/com.birthdayapp/files/crash_log.txt
```

Скопируйте **весь вывод** (стек ошибки) и пришлите.

### Способ B: Лог через logcat

В терминале выполните:

```bash
adb logcat -d | grep -A 50 "FATAL EXCEPTION"
```

Скопируйте блок с **FATAL EXCEPTION** и следующими ~50 строками и пришлите.

## Шаг 3. Пришлите лог

Вставьте скопированный лог в ответ (или в следующий запрос). По нему можно будет точно сказать, что ломается, и что поменять в коде.

---

**Что уже сделано в проекте:** включён MultiDex (много нативных модулей), при краше стек пишется в `crash_log.txt` внутри приложения. После выполнения шага 2 у вас будет точная причина падения.
